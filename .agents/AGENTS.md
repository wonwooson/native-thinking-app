# 프로젝트 공통 규칙 (Workspace Rules)

## 자동화 배포 규칙 (Auto-Deployment Rule)
- **트리거:** 프로젝트에 새로운 기능이 추가되거나, 버그가 수정되거나, 중요한 코드 변경 작업이 완료되었을 때.
- **행동 지침:** 작업이 성공적으로 완료되었다고 판단되면, AI는 명시적인 지시가 없더라도 사용자에게 "구글 클라우드에 변경 사항을 배포할까요?"라고 묻고, 사용자가 동의하면 즉시 `npm run deploy:gcp` 명령어를 실행하여 배포 절차까지 자동화해야 합니다.

## 배포 전 빌드 검증 규칙 (Pre-deployment Build Check)
- **트리거:** 코드 변경 작업 완료 후 배포 전 단계에서.
- **행동 지침:** GCP 환경(Docker 빌드)에서 Typescript의 사소한 경고(Unused import 등)로 인해 배포가 실패하는 일이 빈번히 발생했습니다. 따라서 `deploy:gcp`를 실행하기 전에는 반드시 `npm run build` 명령어를 로컬에서 실행하여 사전에 TypeScript 컴파일 에러나 경고가 없는지 검증해야 합니다. 빌드 성공을 확인한 후 배포를 시작하세요.
